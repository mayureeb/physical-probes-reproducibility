# Mapping the paper to executable studies

The study identifiers below are the original identifiers used in the code and records. The full runner includes the prerequisites automatically.

| Paper evidence | Study / command | Main outputs |
| --- | --- | --- |
| Clean-trace ceiling, paired noisy views, hidden-state positive control | `--study E023` | `experiments/E023_information_ceiling/audit/results.json` |
| TartanDrive history prediction and terrain transfer | `--study E024` | `experiments/E024_real_dynamics_history/results.json` |
| Matched actions, finite-pool ambiguity, same-decoder and masked-input controls | `--study E025` | results, interval-tolerance and noise-covariance audits |
| Learning curves and decision-aware loss | `--study E026` | scaling and paired-objective results |
| Fresh-world tolerance and sampling contrasts | `--study E027` | confirmatory comparisons, landing errors |
| Learned action versus estimated-/true-state planning | `--study E028` | planner intervention comparisons |
| Observation budgets and state estimation | `--study E029` | sampling comparisons and parameter NMSE |
| Task-selected versus D-optimal/fixed probes | `--study E030` | selection, estimator/action locks, test results |
| Bounded direct simulator fitting | `--study E031` | direct-fit comparison and parameter recovery |
| Reference-pool Bayes, path-cap, equivalence, local sensitivity diagnostics | `--study diagnostics` | labeled post hoc outputs |

`reference_results/` preserves recorded outputs for comparison, not as substitutes for running experiments. Each retained file has a provenance hash. `scripts/reanalyze.py` recomputes the E027–E029 rates, paired 20,000-resample intervals, exact tests, and Holm corrections from the released physical landing-error arrays. It does not regenerate those errors.

After a fresh rerun, use `python scripts/compare_results.py`. It reports numerical deviations, skips timing/environment/file hashes, and lists studies not rerun. Discrete model selection and GPU floating-point differences can alter results; inspect changes rather than increasing tolerances until a check passes. Exact agreement is not promised across hardware, operating systems, or package builds.

The paper's earlier E003–E022 experiments are historical context, not primary evidence for its central claims. This release contains only the E014/E020/E021 simulator dependencies from that earlier work, rather than all earlier pilot pipelines. Those historical results are not independently regenerated by the runner. No unpublished experiments or original Git history are included.

Study-specific meanings matter: physical completion is based on replayed landing error; interval membership is used for model/probe selection and some explicitly post hoc diagnostics. These predicates can differ near finite-resolution interval boundaries. Do not substitute interval membership for the physical completion values.

The TartanDrive evaluator computes aggregate nRMSE as the square root of the mean squared residual after channelwise normalization by training scales. Targets are future absolute longitudinal velocity, lateral velocity, and yaw rate, not their differences from the present.
